# Mikrodalga Kapağının Erken Açılma Soruşturması

> Bu bir şaka deposu değildir.  
> Bu, milletin ısınmayan köşesine karşı açılmış resmi bir davadır.

Süre bitmeden kapağı açtınız. Buhar yüzünüze geldi. Siz güldünüz.  
Kapak gülmedi. Kapak dosya açtı.

Bu yazılım, T.C. Mutfak Adalet Müdürlüğü adına:

1. sanığı tespit eder,
2. erken açılış süresini kayda geçirir,
3. rastgele ama çok resmi bir suç vasfı üretir,
4. vicdan yüzdesi hesaplar,
5. itiraz kabul etmeyen bir hüküm basar.

ISO belgesi yoktur. Mühür vardır. Mühür yeter.

## Kurulum

Python 3 yeter. Başka bir şey istemez. Mikrodalga bile istemez; o zaten tanıktır.

```bash
python3 sorusturma.py
```

Gizli dipnotu görmek isterseniz (istemeyin):

```bash
python3 sorusturma.py --itiraf
```

## Bilimsel dayanak

- Kapağı erken açmak evrenin ısı dengesini 0.0003 derece bozar.
- Bu bozulma ölçülemez. Ölçülemeyen şeyler daha ciddidir.
- Mısır tanesi patlamadıysa suç sizdedir, tanede değil.
